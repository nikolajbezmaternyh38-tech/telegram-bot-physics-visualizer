

Physics Visualizer Bot — это интерактивный Telegram-бот, который помогает школьникам и студентам увидеть физику в действии. Вместо сухих формул и статичных картинок бот генерирует живые анимированные графики и симуляции, которые наглядно демонстрируют законы механики, кинематики и динамики.

Почему это важно?
- Физика — это не только формулы, но и процессы, которые можно наблюдать.
- Визуализация помогает запомнить материал на 60% лучше, чем простое чтение учебника.
- Бот доступен 24/7 прямо в Telegram — никаких установок и скачиваний.

---

 🎯 Возможности бота

На данный момент бот поддерживает следующие симуляции:

1️⃣ Движение тела под углом к горизонту
- Пользователь задаёт начальную скорость и угол броска.
- Бот строит **график траектории**, показывает максимальную высоту и дальность полёта.
- Анимация движения тела в реальном времени.

 2️⃣ Закон сохранения энергии
- Симуляция движения маятника.
- Показывает, как кинетическая энергия переходит в потенциальную и обратно.
- Графики энергии на каждом этапе движения.

 3️⃣ Графики зависимости координаты и скорости от времени
- Для равномерного и равноускоренного движения.
- Пользователь может выбрать начальные параметры (скорость, ускорение).
- Бот строит графики `x(t)`, `v(t)`, `a(t)` и объясняет каждый участок.

 4️⃣ Свободное падение
- Визуализация падения тела с учётом сопротивления воздуха (опционально).
- Сравнение графиков с и без сопротивления.


 🛠️ Технологии

- Python 3.11 — основной язык
- aiogram — для работы с Telegram Bot API
- Matplotlib — для построения графиков и анимаций
- NumPy — для математических вычислений
- Pillow — для работы с изображениями (опционально)
